# fechaSemana

Small JavaScript project that processes an array of names and calculates
the length of each name and the total number of characters.

## Requirements

- A web browser (Chrome, Firefox, Edge...) **or** [Node.js](https://nodejs.org/) 18 or later
- Git

## Installation

1. Clone the repository:

```bash
   git clone https://github.com/AlejandroNeron/fechaSemana.git
```

2. Enter the project folder:

```bash
   cd fechaSemana
```

## Configuration

No configuration is needed. The project has no external dependencies.

## Usage

### Option A: Node.js

```bash
node fechaSemana.js
```

Expected output:

```
[ 5, 4, 5, 7, 5 ]
26
```

### Option B: Browser

1. Open `fechaSemana.html` in your browser.
2. Open the developer tools (F12) and go to the **Console** tab.
3. The same output will appear there.

## Project structure

- `fechaSemana.js`: main script, documented with JSDoc
- `fechaSemana.html`: page that loads the script
